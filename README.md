## Project Overview
An interactive dashboard designed to analyze Amazon India sales and business performance through clear visualizations and KPIs.

## Business Objectives
- Monitor overall sales and profitability.
- Identify high-performing product categories.
- Analyze delivered, shipped, returned, and cancelled orders.
- Evaluate payment and fulfilment methods.
- Compare business performance across Indian states.

## Key Performance Indicators
- Total Sales
- Total Profit
- Total Orders
- Total Units Sold
- Average Order Value
- Profit Margin
- Return Rate
- Cancellation Rate

## Dashboard Sections
1. Executive Overview
2. Product Analysis
3. Order Analysis
4. Business Operations

- Microsoft Excel

- HTML, CSS, and JavaScript
